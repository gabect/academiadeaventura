# Mountain Studio v0.55.0 — connective tree anatomy

Problem observed: cut, detached field-pine trunks; fork branches with hard seams; foliage cards scattered around rather than rooted in supporting branches.

Studio-only changes:
- Crown stems overlap existing external field trunks, without modifying collisions or paths.
- Curved two-span branch geometry, woody junction collars, unified bark colour maps for instanced mountain trunks and all tree branches.
- Pine needle buds and broadleaf leaf clusters anchored to actual branch/twig nodes; broadleaf leaves now sit closer to branch endpoints.
- Preserve six unique pine and five broadleaf silhouettes, painterly maps, full ground cover from v0.51, normal gameplay and normal mode.
- Geometry generated once and GPU instanced where supported; run real WebGL screenshot suite before accepting.

This does not assert final art parity or real mobile GPU performance.
