# Mountain Studio tree artwork (v0.60)

Source: Tree Sprites by klamtii, https://klamtii.itch.io/tree-sprites

The source archive contains a license permitting copying, modification,
distribution and derivative works, including commercial projects, without
advance permission. Attribution is appreciated but not required.
Please refer to the original .license.txt for exact wording.

The source trees were rendered in Blender by klamtii. The Studio build
selects eleven assets, corrects color values and packs them into local
transparent PNG atlases. No external network request is made at runtime.

The previous v0.59 procedural tree art was rejected as visually inadequate.
