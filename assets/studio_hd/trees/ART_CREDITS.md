# Whole-tree artwork (Studio v0.60)

The illustrated tree PNG placeholders in v0.59 are replaced with sprites from **Tree Sprites** by **klamtii**: https://klamtii.itch.io/tree-sprites.

The author explicitly permits copying, modifying, distributing, deriving from, and commercial use of the images without requiring attribution. Attribution is included voluntarily. The source includes 30 individually rendered transparent PNG sprites in groups A–J. We use eleven permitted trees from groups A–F, cropped, color balanced and packed into two texture atlases.

All tree-atlas generation occurs at build time. The game does not request assets from itch.io at runtime.
