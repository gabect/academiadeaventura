# Mountain Studio illustrated art assets
Curated directly from user-supplied Adventure Academy concept sprite sheet. 4 opaque tile textures and 11 transparent cut-out image cards. The ZIP stores compressed WebP files, not separate source PNGs.
`assets/studio_hd/tiles`: rock, rock_moss, grass, grass_dense; currently tiles are artistically **mirror-symmetric** and not professionally seamless across arbitrary edges.
`assets/studio_hd/sprites`: grass tuft/medium, fern, broadleaf, flowers white/purple, root, vine, hanging edge, rock outcrop/ledge.
Each sprite has a real alpha channel; in the final material, use alphaTest >= 0.45 to avoid dirty matte. RGB was not color-keyed. Produced only for prototype and pending mobile GPU visual acceptance.
Source rights: user-provided illustrative concept art within this chat. No external copyrighted stock assets.
