# HD Mountain Sprite Trial (v0.44)

The main game remains unchanged unless the URL contains ?hdtest=1.

To enable the experiment, add these transparent PNG sprites under this folder's sprites/ subdirectory:
- grass_tuft_dense.png
- fern_small.png
- broadleaf_cluster.png
- grass_hanging_edge.png
- rock_mossy.png

Source images are supplied in the user-facing Adventure_Academy_HD_Prototype.zip / mountain_hd_assets_v1 package.

The prototype is restricted to X=-65..-46, spawns up to 280 non-colliding decorative planes, and preserves terrain/camera/character physics. Missing PNG files silently skip the trial and log a warning.

Note: sprites for this test are not included yet. Do not claim this experimental feature is live until uploaded and verified.
